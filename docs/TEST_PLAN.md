# ReallyZip 功能测试计划

- **版本**：v0.1.0
- **被测对象**：`reallyzip.exe`（Windows x64 单文件 GUI 压缩工具，commit `6d53fa3`）
- **编写日期**：2026-08-11
- **执行方式**：全自动（脚本驱动 + `cargo`/`gh` 工具链），结果汇总至 `TEST_REPORT.md`

---

## 1. 测试目标

对 ReallyZip 进行覆盖「冒烟 → 单元/集成 → 命令行端到端（真实压缩/解压）→ 资源管理器右键菜单 → 跨工具互操作 → 异常与边界」的完整功能验证，确认核心压缩/解压引擎与右键菜单集成行为正确、健壮，并产出可复现的测试报告。

## 2. 测试范围

### 2.1 纳入自动化
- 构建产物冒烟（存在性、体积、单文件）
- 单元 / 集成测试（`cargo test`）：AES-256 密码、分卷拆分合并、压缩核心
- 命令行无头端到端：
  - 压缩：多文件、单文件、目录树、含空格/中文/Unicode 文件名、目标冲突自动命名、空目录
  - 解压：`--extract-here` 到同名文件夹、保留目录层级
  - 大文件（≥50 MB）压缩→解压内容一致性（哈希比对）
  - 跨工具互操作：ReallyZip 生成的 zip 能被 Python `zipfile` 正确读取；Python 生成的 zip 能被 ReallyZip 正确解压
  - 异常与边界：不存在的路径、非 zip 文件、空目录
- 右键菜单注册 / 注销（`--register-shell` / `--unregister-shell`）：注册表结构、命令指向稳定路径、清理无残留、重复注册无孤儿

### 2.2 不纳入自动化（需 GUI，标注为人工验证）
以下路径依赖 egui 窗口交互，无法在无显示环境驱动，但其底层函数已被单元测试与无头 CLI 覆盖，报告中标注为「人工验证」：
- 压缩对话框全选项（压缩级别、AES-256 密码、分卷 `.zip.001`、追加/删除）
- 压缩包内浏览 / 预览 / CRC32 校验 UI
- 解压对话框（选择目标路径）
- 设置页「注册右键菜单」按钮交互（其底层 `shell::register()` 已自动化验证）

## 5. 通过准则

- 每条用例「实际结果 == 预期结果」且无非预期副作用（残留文件、崩溃、错误日志）即判 **PASS**。
- 断言失败、进程异常退出（非零且无预期）、产物不符、残留文件即判 **FAIL**，记入缺陷表。

为什么选择 ReallyZip

把常用压缩操作收进一个干净的工具里，少装插件、少弹窗。

AES-256 加密

压缩即用密码保护，标准 ZIP 格式，可被其他工具正常解压。

级联右键菜单

资源管理器右键收纳为单个「ReallyZip」子菜单，不刷屏、不重复。

单文件绿色

一个 exe 即可运行，无需安装、无运行时依赖，放 U 盘随身带。

多选批量

一次选中多个文件 / 文件夹，右键一次完成压缩，自动收纳。

直接压缩到当前目录

--compress-here 一键生成同名 zip，不弹窗，适合批量脚本。

解压到同名文件夹

右键「解压到同名文件夹」，自动建目录，不再把文件撒一桌。

不刷屏的右键菜单

采用 Windows 原生级联菜单（ExtendedSubCommandsKey），所有入口收进一个「ReallyZip」子菜单。

文件 / 文件夹

加入压缩包…、压缩到此处。多选时一次调用，自动打包。

.zip 压缩包

打开、解压到…、解压到同名文件夹、追加文件。已避免顶层重复入口。

文件夹空白处

目录背景右键同样提供压缩入口，随手打包当前内容。

三步上手

下载即用，也可一键把右键菜单装上。

1

下载并运行

双击 reallyzip.exe 即可打开图形界面，无需安装。

2

注册右键菜单

把 install.bat 与 exe 放一起，双击运行即可注册「ReallyZip」右键菜单；uninstall.bat 可一键撤销。

3

右键即用

在文件 / 文件夹 / .zip 上右键，选择压缩、解压或追加，弹窗少、效率高。

文档与参考

完整功能、命令行用法与技术栈，一页看完。

功能特性（完整）

  • 创建 / 解压 ZIP，六档压缩级别（存储 ~ 最大压缩）
  • AES-256 加密：密码加密与解密
  • 分卷压缩 .zip.001 / .002…（与 7-Zip 兼容），打开自动合并
  • 包内浏览：不解压查看目录树，预览文本 / 二进制
  • 追加与删除：向已有压缩包追加（跳同名）、删除条目（无损重写）
  • 完整性测试：逐条校验 CRC32
  • 右键级联菜单（HKCU，无需管理员、无需 COM）
  • 拖拽压缩：把文件拖进窗口即可压缩

命令行参考

# 右键菜单
reallyzip --register-shell
reallyzip --unregister-shell
# 压缩 / 解压
reallyzip --compress "文件1" "文件2"
reallyzip --compress-here "文件1"
reallyzip --extract-to "a.zip"
reallyzip --extract-here "a.zip"
reallyzip "a.zip"

cargo build --release # 产物 target/release/reallyzip.exe
